# 第二问安全候选区域与第二检测点选择算法总结

> 历史版本2说明。对应实现现冻结于 `legacy_selection_v2.py`；最新算法及验证入口见 [版本3说明](Q2_ALGORITHM_SUMMARY.md)。本文其余内容保留原版本口径。

论文验证材料见 [Q2 结果验证与可视化](validation_results_v2/Q2结果验证.md)，图表安排与复现方法见 [验证说明](VALIDATION_README.md)，修复前后的配对结果见 [修复与验收报告](Q2修复与验收报告.md)。本文件完整说明当前 `selection.py` 中的版本2算法。

第二问包含两个核心任务：根据某全向干扰源在首个检测点得到的示向度，给出第二检测点的候选区域；在候选区域内选择能取得较好定位效果的位置。为完成这两项任务，先构造包含所有可能源位置的初始定位外包，再建立保证再次收信的安全区域，最后比较各测点可能产生的第二次观测对定位区域的收缩效果。

算法输入首测点坐标、示向度及误差界，可附加当前位置、已测位置与搜索参数；输出安全候选区域、推荐第二测点、连续方向响应的保守半径上界、近优点云及计算状态。源位置只用于事后验证，不进入选点算法。第二问不需要连接模拟器。

依据仓库 `26/B题/B题.pdf` 的问题二及附录1—2。初始集合定位、安全候选区域与Q1几何复用对应 `b_algorithm_implementation_spec.md` 第4—6节；当前连续响应上界与默认精度优先策略以本文件及代码为准。题面未提供第二问的固定数值观测数据，验证案例均为合成案例。

## 问题拆分与算法逻辑

### 1 构造初始定位外包

设首测点为 s1，示向度为 θ1，统一误差半宽为 δ=1°。W(s,θ,δ) 表示顶点在 s、中心方向为 θ、两侧各扩张 δ 的前向角域。真实源 G 同时满足目标圆约束和首次有效收信的距离上界：

```text
G ∈ W(s1,θ1,δ) ∩ B(O,1800) ∩ B(s1,1500)
```

有效接收半径虽然未知，但不超过1500m，因此首次方向响应提供了最后一项约束。正常示向还意味着站源距离大于5m；当前算法保留包含近距部分的凸外包，不实施会使区域非凸的5m排除。

程序将目标圆和接收圆分别替换为外切正多边形，默认每个圆128边，再与首次前向角域求交，得到 P+。外切多边形包含真实圆，故真实可行源始终属于 P+。初始化复用Q1的半平面求交：检查可行性和有界性，枚举可行边界交点、去重并构造凸包，同时计算最小包围圆。

Q1计算纯测向角域交；Q2的 P+ 额外包含目标圆和首次接收距离信息。两个区域的定义不同，论文中的面积、直径和半径必须注明对应哪一种区域。

### 2 给出保证再次收信的候选区域

设 P+ 的顶点集为 V。全向源有效接收半径至少1000m，预留0.1m安全裕量，令 ρ=999.9m，定义

```text
C_safe = {s : max_{v∈V} ||s-v|| ≤ ρ}
       = ∩_{v∈V} B(v,ρ)
```

对固定 s，距离函数在凸多边形上的最大值可在顶点取得。因此 s∈C_safe 时，到 P+ 内任意源位置的距离都不超过999.9m，保证全向源再次收信。该区域可超出目标圆，这是题目允许的测点位置。

程序以圆盘交的定义、圆盘公共半径、安全见证点和包围盒描述连续候选区域；圆心就是 `initial_region.vertices` 中的顶点。绘图的边界使用数值等值线，选点安全性直接逐顶点核验，不依赖图像或边界插值。

### 3 构造安全后备测点

计算 V 的最小包围圆，其圆心、半径为 c、R1。C_safe 非空当且仅当 R1≤ρ，c 即安全见证点。令

```text
slack = ρ - max_{v∈V} ||v-c||
```

若 ||s-c||≤slack，由三角不等式有 ||s-v||≤slack+||c-v||≤ρ，因此见证点周围半径 slack 的圆盘也位于安全区域内。

程序先尝试 c；若 c 与已测位置重复，且 `slack > 2 × repeated_position_tolerance_m`，则在半径 slack/2 的圆周上构造 `2 × 已测位置数 + 8` 个均匀方向的替代点。依次检查收信安全性及与所有已测位置的距离，取首个合格点作为后备点。首测点自动加入已测位置集合。

后备点不依赖源场景采样或网格恰好命中可行区域。建立后备点后，先给它赋予通用上界 `R1 + 1e-6m`；即使没有时间完成进一步评分，也有一个安全结果可返回。若安全区域为空，或当前构造无法找到通过重复位置过滤的见证点，则分别返回明确的失败原因。

### 4 生成有限候选点

在安全区域的包围盒内生成默认100m间距的粗网格，网格以见证点对齐；同时加入见证点、顶点坐标平均值及当前位置作为原始候选。随后去重、逐顶点检查安全条件，并排除距已测位置不超过1e-6m的点。顶点平均值仅是辅助候选，不被用作无条件安全圆心。

若合格点超过粗候选上限，先按移动距离保留约三分之一的近点，再用最远点优先规则选取分散代表：先取最靠近见证点的点，然后反复选择到已选集合的最小距离最大的点。两部分合并去重后最多保留24个粗候选，安全后备点另行加入。

粗评分完成后，在最优粗候选的 x、y 两方向各扩展100m，使用20m细网格；安全过滤后以同样的分散选取规则保留最多24个细候选，移除已经评分的位置再计算。粗、细候选上限分别生效；后备点单独加入，所以不能把总评分次数写成固定48次。

### 5 为每个测点确定完整的可能读数范围

对候选 s，计算所有顶点相对于 s 的方位角并排序，在圆周相邻角度间寻找最大空隙。去掉该空隙后的最短覆盖弧，包含所有顶点方向。

若覆盖弧宽小于180°，顶点向量落在同一个开半圆内，所有凸组合的方向也落在该角锥中。将覆盖弧两端各扩张 δ，并另加1e-8°数值裕量，就得到覆盖全部可能第二示向读数的区间。若覆盖弧不满足开半圆条件，或 s 距某顶点不超过1e-7m，则直接采用完整360°，保守处理候选在区域内部或边界附近的情形。

角度区间使用连续展开的表示，允许端点小于0°或大于360°；构造角域时再归一化，所以跨0°不会漏掉响应。

### 6 计算连续响应的保守定位半径上界

设第二示向读数为 θ，观测后的更新外包为

```text
P(θ) = P+ ∩ W(s,θ,δ)
```

对读数区间 I=[m-h,m+h]，任意 θ∈I 满足

```text
W(s,θ,δ) ⊆ W(s,m,δ+h)
P(θ) ⊆ E(I) = P+ ∩ W(s,m,δ+h)
```

因此 E(I) 的最小包围圆半径给出该区间内所有更新半径的上界。如果 δ+h≥90°，当前两半平面模型不表示这一宽角域，程序直接使用整个 P+ 的包围圆作为上界，再通过细分收紧。

窄区间通过逐边半平面裁剪构造 E(I)，复用Q1的最小包围圆函数计算半径。半径重新遍历全部顶点核算，并加1e-6m裕量；还与初始区域的上界取较小值。空区间外包的贡献记为0，表示该区间没有需要覆盖的方向更新区域，不是将 near 误差记成0。

所有当前叶区间始终完整覆盖可能读数范围，取其上界最大值：

```text
U(s) = max_{I为当前叶区间} upper_radius(I)
```

程序同时计算区间中点 m 对应的实际更新区域 P(m) 的半径，保存已计算中点半径的最大值 L(s)。优先二分当前上界最大的叶区间，直至 `U(s)-L(s)≤0.5m`、达到64个叶区间上限、预算耗尽，或浮点端点已无法继续二分。

只有两个子区间均计算完成后才替换父区间；若计算左子区间后预算耗尽，则保留父区间。这样提前停止仍保留完整角度覆盖和有效上界。L(s) 是针对外包区域所有方向的采样下界，不一定由真实物理源实现；细化差不能解释成相对真实可行源最坏值的精确误差。

### 7 按精度目标选点并输出近优点云

设狗当前位置为 p、移动速度为 v=5m/s，目标函数为

```text
J(s) = U(s) + λ ||s-p|| / v
```

默认 λ=0，优先使最坏定位半径的保守上界尽可能小；需要时间折中时，可显式设置 λ=1m/s 或其他非负权重。评分相同时依次比较移动距离、x坐标、y坐标，保证选取规则确定。

从已记录的评分结果中选择 J 最小的点；将 `J≤J_min+10m` 的位置去重后作为近优点云。这里“近优”只相对于已生成并评分的候选及其保守上界，不代表整个连续安全区域中的全局近优点集。

## 数学结论

**再次收信保证。** 若实际源 G∈P+，且推荐点 s 满足全部顶点距离不超过ρ，则由凸性可得 ||s-G||≤ρ<1000m。对题设的全向源，这足以保证再次收到信号；距离不超过5m时可能得到 near，而非 direction。

**候选区域非空判据。** `∩_v B(v,ρ)` 非空等价于存在一个圆心，使所有顶点都在半径ρ的圆中，即最小包围圆半径不超过ρ。见证点及其内部安全球由这一判据与三角不等式构造。

**连续方向响应上界。** 最小包围圆半径对集合包含关系单调：A⊆B 时 R(A)≤R(B)。由 `P(θ)⊆E(I)` 及叶区间的完整覆盖，可得对全部合法 direction 响应均有

```text
R(P(θ)) ≤ U(s)
```

因此上界的依据是连续角域的包含关系，不是有限误差样本碰巧覆盖最坏情况。圆外包、额外保留的源位置和不一定可实现的读数可能使上界偏保守。

**最优性边界。** 上界覆盖连续响应，但候选测点搜索仍为有限近似，区间上界也可能尚未细化到目标容差。当前算法给出具有安全依据、可数值验证的精度优先策略，不声称求得整个安全候选区域的全局最优点。

## 输入输出约定

入口为 `choose_second_detection(first_observation, error_deg=1.0, current_position=None, used_positions=None, config=None)`。

`first_observation` 必须且只能包含 `position: {x,y}` 与 `svd_deg`；当前位置与已测位置的每一项也必须且只能包含 x、y。坐标和距离单位为米，示向度从正东方向逆时针计量，角度自动归一化。数值输入应有限，不接受NaN、Infinity或布尔值冒充数值。

默认 `error_deg=1.0` 为题设误差界，要求 `0<error_deg<90`。若研究读数量化裕量，可显式传入1.005，但它不是当前默认或题设规定。当前位置默认首测点；已测位置默认仅含首测点，外部附加列表只能用于重复测点过滤，不会自动添加新的观测约束。接口假定输入为合法首次 direction 观测，不接收 near 或 no_signal 结果作为示向数据。

## 几何公式与完整计算流程

观测点为 s，令 l=(cos(θ−δ),sin(θ−δ))、r=(cos(θ+δ),sin(θ+δ))。前向角域转换为

```text
(l_y,-l_x)·x ≤ (l_y,-l_x)·s
(-r_y,r_x)·x ≤ (-r_y,r_x)·s
```

对圆心 o、半径R的圆盘，令 `n_k=(cos(2πk/M),sin(2πk/M))`，其M边外切多边形由 `n_k·x≤R+n_k·o` 表示。顶点相对真实圆周的最大径向超出量为 `R(sec(π/M)−1)`，说明外包误差方向是保守的。

安全区域包围盒的两个分量分别为 `lower=max_v(v−ρ)`、`upper=min_v(v+ρ)`。更新多边形逐半平面裁剪：计算相邻顶点的有符号残差，保留内侧端点；边跨越边界时按 `p+(q−p)f(p)/(f(p)−f(q))` 插入交点，之后去重。最小包围圆复用Q1的小规模确定性算法，枚举单点、点对中点和非共线三点外心，逐个重新检查所有顶点的覆盖半径。

主流程可概括为：

```text
校验首次观测、误差界、位置与配置；从入口建立可选截止时间
构造初始外包P+，取得顶点V和包围半径R1
若初始几何不是BOUNDED，返回GEOMETRY_ERROR及底层原因
构造安全圆盘交；若为空，返回NO_CANDIDATE / SAFE_REGION_EMPTY
构造通过安全和重复点检查的后备点s0
若无法构造，返回NO_CANDIDATE / NO_UNUSED_SAFE_WITNESS
记录s0及通用上界R1+数值裕量
预算允许时生成粗候选，逐个用完整角度区间分割计算U和J
按(J,移动距离,x,y)取最优粗结果
预算允许时围绕它生成细候选，对未评分的位置计算U和J
从全部记录取最佳结果，输出近优点云和实际预算状态
```

`build_initial_outer_region` 返回 `(result,A,b)`；`safe_candidate_region` 构造区域描述；`is_safe_candidate` 提供成员检查；`response_radius_bound` 实现连续读数区间上界。几何辅助函数位于 `B.q2.selection`，通常由经输入校验的主入口调用。包级入口 `B.q2` 导出 `Q2Config`、`choose_second_detection` 和 `safe_candidate_region`。

## 失败状态、预算与反馈边界

初始几何的 EMPTY、UNBOUNDED 或 NUMERICAL_ERROR 在Q2主入口统一返回 `GEOMETRY_ERROR`，底层状态保留在 `reason`，不伪造推荐测点。参数格式或数值不合法时抛出 `ValueError`，不作为正常几何失败处理。

`SAFE_REGION_EMPTY` 只说明保守区域无候选；`NO_UNUSED_SAFE_WITNESS` 说明当前见证构造没有通过已测位置过滤，程序此分支在网格搜索前退出。这些状态均不构成对真实物理问题无解的证明。正常题设输入仍须以连续安全证明和合法边界检验共同确认实现。

预算从主函数入口开始计时，包含初始化。它是协作式预算：初始几何、候选生成和单次计算不能强行中断；超限后停止进一步排名，返回当前最好安全记录。若未完成任何候选评分，可以返回 `selection_mode=safe_fallback` 的初始覆盖上界。`timed_out=true` 可以与 `status=OK` 同时出现；默认预算为None时的零超时不说明硬实时性能。

当前模块输出第二测点，不实际发出检测或清除请求。收到后续 direction 时，上述更新公式适用；near 表示按题设可直接光学定位清除，不表示无线电区域已缩成一个点；no_signal 不用于本模块的初始外包裁剪。保证收信的推导仅适用于全向源，未知朝向的定向源不能直接套用。

## 正确性确认

当前算法与验证程序已有以下分层证据，详细原始数据保存在版本2结果目录：

1. **初始包含与安全候选**：外切圆测试、真实源包含、最小包围圆非空判据，以及推荐点和近优点云逐顶点距离检查。
2. **连续上界与几何更新**：独立边界交点枚举、独立支撑圆计算和密集角度核验；覆盖跨零、测点在区域内外等布局。
3. **边界与中断**：近切圆周及极限首次误差、重复见证点替代、区间数耗尽、细分中途预算耗尽、near不记零几何半径。
4. **确定性与效果**：相同输入得到相同推荐点和评分，旧30例配对比较及新60例共享验证场景的五策略对照。
5. **细化与预算行为**：10例固定测点的区间上限16、32、64、128加密后上界不增；三档小预算均安全返回。

上一轮验收中Q2的18项测试全部通过，共用Q1的18项测试也全部通过。本文件是对已实现算法的整理；测试通过支持当前输入范围与浮点容差下的正确性，不能代替任意病态输入下的数值精确认证。

## 方案对比与最终选型

| 子任务 | 当前采用方案 | 选择原因 |
| --- | --- | --- |
| 初始区域 | 前向角域、目标圆与接收圆的凸外包 | 使用可获得的物理信息，保留真实可行源 |
| 候选区域 | 外包顶点的999.9m圆盘交 | 对连续源区域给出再次收信依据 |
| 后备测点 | 最小包围圆心及内部安全球中的替代点 | 避免依赖源样本或粗网格命中窄区域 |
| 观测效果评价 | 示向区间外包与自适应二分 | 为完整连续方向响应给出保守半径上界 |
| 定位尺度 | 最小包围圆半径 | 与整个定位区域的覆盖需求一致；不以直径的一半代替 |
| 测点搜索 | 粗细网格、附近点与分散代表点 | 在有限计算量下兼顾可复核性和空间探索 |

## 计算规模、数值容差与适用范围

若初始半平面数为n、顶点数为v，初始化继承Q1：交点筛选约O(n³)、直径计算O(v²)、参考最小包围圆O(v⁴)，另有线性规划状态检查。对一个候选，每次区间评估最多计算区间外包和中点更新两个包围圆；半平面裁剪为线性遍历。设K为评分候选数、B为叶区间上限，则主要评分成本可按 `O(KB(v+2)^4 + KB²)` 估计，后项来自当前对最大上界区间的线性搜索。候选网格生成、去重及分散筛选另有成本，这不是整个函数的完整复杂度上界。

初始求交沿用Q1的1e-7m几何容差和HiGHS 1e-9可行性容差；更新裁剪的残差及相邻点去重容差为1e-8m，候选常规去重为1e-7m，安全距离成员检查允许1e-9m浮点比较余量，响应半径另加1e-6m。米制裕量与角度裕量分开使用。参数预算不会把Python函数变成硬实时程序。

当前结果支持第二问的安全候选区域与较好定位效果策略。候选区域为保守安全子集，测点搜索为有限近似，浮点实现不是严格区间算术证书。第二次观测也不保证在每个场景都达到20m清除条件；若后续需要清除，仍应对实际更新区域核验覆盖圆。以上实验为离线合成结果，不能写成官方模拟器成绩，第二问本身不要求Q3/Q4的三次正式测试。
