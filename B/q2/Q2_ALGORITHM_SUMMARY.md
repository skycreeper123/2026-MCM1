# 第二问安全候选区域与主动选点算法总结

第二问输入一个全向干扰源在首个检测点得到的示向度，需要给出第二检测点的候选区域，并从中选择定位效果较好的位置。算法复用第一问的半平面交和最小包围圆，不连接模拟器。

## 初始定位外包

首个示向度左右各扩张 1° 得到前向角域。真实源还满足位于半径 1800m 的目标圆内，并且因已经收到信号而距首个检测点不超过 1500m。程序用外切正多边形近似两个圆，构造包含真实可行集的凸外包 `P+`：

```text
P+ = 示向角域 ∩ 目标圆外包 ∩ 首测点1500m接收圆外包
```

外切而非内接近似确保不会排除真实干扰源。

## 保证再次收信的候选区域

全向源的有效接收半径至少为 1000m。设 `V(P+)` 为外包顶点，则安全候选区域定义为：

```text
C_safe = {s: max_{v in V(P+)} ||s-v|| <= 999.9m}
```

距离函数在凸多边形上的最大值由顶点取得，因此任何 `s∈C_safe` 到 `P+` 内所有可能源位置的距离都不超过 999.9m，从而严格小于最小接收半径 1000m。这个保证适用于连续的整个外包区域，不依赖有限采样。

`C_safe` 等于以每个外包顶点为圆心、999.9m 为半径的闭圆盘交。它非空当且仅当这些顶点的最小包围圆半径不超过 999.9m；对应最小包围圆圆心提供一个确定的安全见证点。程序输出其定义、见证点、保证裕量和包围盒，不把离散候选点云误称为完整候选区域。

## 第二检测点选择

在安全候选区域内生成粗网格，并保留最小包围圆圆心、区域中心和邻近代表点。排除已经检测过的位置，随后对最优粗候选附近做细网格搜索。

对每个候选点 `s`，从真实物理区域中确定性选取有限源位置场景 `g`，并枚举第二次示向误差 `e∈{-δ,0,+δ}`。若 `||s-g||<=5m`，模拟反馈为 `near`，后续定位半径记为 0；否则生成模拟示向度并用第一问几何更新外包。候选评分为：

```text
J_hat(s) = max_{g,e} updated_cover_radius(s,g,e)
           + movement_weight * ||s-current_position|| / 5
```

默认移动权重为 1m/s，使移动时间项换算为米后与定位半径相加。选择评分最小的候选，并输出评分在最优值加 10m 内的候选点云。

收信保证和选点评分的性质不同：`C_safe` 是连续区域上的确定性保证；`J_hat` 只是在有限源位置和误差场景上的离散近似，不能宣称为连续最坏情形的全局最优解。

## 主要接口

```python
from B.q2 import Q2Config, choose_second_detection

first = {"position": {"x": -1000.0, "y": 0.0}, "svd_deg": 0.5}
result = choose_second_detection(first, config=Q2Config())
print(result["status"], result["selected"])
```

`status="OK"` 时，`selected.position` 是推荐第二检测点；`safe_candidate_region` 描述完整安全候选区域；`near_best_candidate_cloud` 只是近优离散点集。若保守外包的安全交集为空，返回 `NO_CANDIDATE`，不能据此声称真实问题没有可行点。

## 边界和适用范围

- 只对全向干扰源给出再次收信保证；未知方向的定向源不适用。
- 同一地点的误差固定，因此排除已经检测过的位置。
- `no_signal` 不用于收缩初始定位外包。
- 当前圆外包默认使用 128 条切向半平面；边数越多越紧，但计算量也增加。
- 排名达到计算时间上限时返回已经得到的最佳候选；没有完成的离散搜索不影响所选点的安全收信性质。
- 第二问的“较好”采用最坏更新包围半径与移动时间的组合指标；权重属于可调参数，不是题目给定常数。
