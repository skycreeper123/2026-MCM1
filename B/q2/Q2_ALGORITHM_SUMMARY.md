# 第二问：安全候选区域与精度优先选点（版本2）

当前方案保留有界误差的集合定位模型，改用连续示向响应的保守半径上界评价测点，默认优先定位精度。算法不需要真实源坐标，不连接模拟器。版本1的源场景采样已移除，窄区域不再因漏采样而无法选点。历史结果保留在 `validation_results/`，新结果写入 `validation_results_v2/`。

## 初始外包与安全候选区域

设首次站点为 s1、示向度为 θ1、误差半宽 δ=1°，W(s,θ,δ) 表示前向角域。令

```text
P+ = W(s1,θ1,δ) ∩ 目标圆外包 ∩ B(s1,1500m)外包
C_safe = ∩_{v∈vertices(P+)} B(v,999.9m)
```

圆采用外切正多边形，默认128边，保留真实圆。正常方向反馈排除5m内源位置，但不实施这一非凸排除，因此 P+ 是保守外包。距离函数在凸多边形上的最大值由顶点取得，所以 C_safe 内的点到全部真实可行源距离小于1000m，保证全向源再次收信。圆盘交的定义、见证点、包围盒在输出中提供；近优点云不是完整候选区域。

C_safe 非空当且仅当 P+ 的最小包围圆半径不超过999.9m。包围圆心 c 是安全见证点，令 slack=999.9−max_v||v−c||。c 周围半径 slack 的球位于安全区域内；如果 c 已测过，就在这个球中构造不同于已测位置的替代点，并重新检查安全条件。源场景或候选网格不再是安全后备点存在的前提。重复点过滤仍有显式容差，若外部过滤条件排除构造见证，返回 `NO_UNUSED_SAFE_WITNESS`，不宣称整个连续安全区域为空。

## 连续响应半径上界

第二次方向读数为 θ 时，更新外包 P(θ)=P+∩W(s,θ,δ)。对读数区间 I=[m−h,m+h]，有

```text
W(s,θ,δ) ⊆ W(s,m,δ+h)， θ∈I
P(θ) ⊆ E(I)=P+∩W(s,m,δ+h)
```

因此 E(I) 的包围圆半径是该区间所有更新半径的上界。如果 δ+h≥90°，不用双半平面表示宽角域，而使用整个 P+ 的包围圆作为有效上界，再细分。

所有顶点相对于候选 s 的方向若落在一个开半圆内，它们的凸组合也在该角锥内；将该方向范围两端扩张 δ 可覆盖全部可能读数。否则使用完整360°。跨0°在展开的连续角度区间上处理。

对覆盖全部读数的区间分割 {Ij}，定义

```text
U(s)=max_j radius(MEC(E(Ij)))
```

于是任何真实可行源、任何合法第二误差产生的方向反馈都满足 radius(MEC(P(θ)))≤U(s)。上界有集合包含关系的数学依据，不依赖测试样本恰好覆盖最坏情况。

程序优先二分上界最大的区间，以已计算的区间中点响应半径最大值作为细化参考。当上界与中点最大值相差不超过0.5m，或达到64个叶区间上限时停止。达到区间上限仍保留有效上界，仅可能更保守；细分中超时保留尚未完整替换的父区间，不丢失角度覆盖。中点下界针对外包的所有方向，未必由真实物理源实现，不能将细化差当作相对真实物理最坏值的误差。

实现沿用Q1的1e-7m几何容差，半径另加1e-6m裕量。该实现为浮点几何，没有使用严格区间算术，不提供任意病态输入下的精确数值证书。

## 候选搜索与目标

安全筛选后，在100m粗网格中保留附近及分散代表点，最多24个；最优粗候选周围用20m细网格，最多24个。安全后备点也参加比较，已测位置被过滤。目标为

```text
J(s)=U(s)+λ||s-current_position||/5
```

默认 **λ=0**，优先满足第二问的定位效果要求，同分优先短移动。需要时间折中时显式设 λ=1m/s 或其他非负权重。U覆盖连续方向响应，但测点搜索仍为有限候选搜索，不能宣称在整个安全区域全局最优。

near 按题设直接进入光学精确定位及清除，不等于无线电几何误差为零；当前半径评分明确针对 direction 反馈，验证统计将 near 单列。

## 接口与预算

```python
from B.q2 import Q2Config, choose_second_detection
first = {"position": {"x": -1000.0, "y": 0.0}, "svd_deg": 0.5}
result = choose_second_detection(first)
tradeoff = choose_second_detection(first, config=Q2Config(movement_weight_m_per_s=1))
```

| 字段 | 含义 |
|---|---|
| `status` | OK / NO_CANDIDATE / GEOMETRY_ERROR |
| `selected.position` | 安全推荐点 |
| `selected.worst_updated_cover_radius_m` | 连续方向响应的保守上界U；版本1此字段为样本预测，语义已加强 |
| `selected.sampled_direction_radius_m` | 已计算中点响应半径最大值 |
| `selected.response_bound_gap_m` | 上界与上述中点最大值之差 |
| `selected.response_bound_converged` | 是否达到区间细化容差，不表示测点全局收敛 |
| `selection_mode` | response_bound_search / safe_fallback |
| `elapsed_s / timed_out / budget_overrun_s` | 全调用耗时、预算是否耗尽及超出量 |

`calculation_time_limit_s` 从函数入口计时，是**协作式预算，不是硬实时期限**：初始几何、候选构造和单次几何运算不能被强行中断。预算耗尽则停止进一步排名，返回已验证的安全测点和仍有效的保守上界；若初始几何或安全见证无法建立，则返回明确失败状态。默认没有预算，零超时不证明硬时限达标。

版本2删除 `scenario_spacing_m`、`max_source_scenarios`、`source_scenario_count`，由 `response_bound_tolerance_m`、`max_response_intervals` 和响应诊断字段代替。不得继续声称源采样数影响当前算法。

回归、独立场景与版本对照见 [验证说明](VALIDATION_README.md)。收信保证适用于全向源；不将Q3/Q4的官方正式测试要求混入第二问。
