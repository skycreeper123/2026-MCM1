# 第一问 交会定位区域直径与圆覆盖

本目录实现问题一的通用算法：输入若干检测点坐标及示向度，输出纯前向角域交集的状态、顶点、直径、最远点对，以及以该直径为直径的圆是否覆盖整个区域。无需登录模拟器，无 HTTP 请求，也不消耗演练或正式测试次数。

依据仓库 `26/B题/B题.pdf` 的问题一及附录二，以及 `b_algorithm_implementation_spec.md` 第 4.2、4.3、5 节。题面没有提供第一问的固定数值数据，`examples/` 均为合成示例。

## 依赖与调用

在仓库根目录使用 Python 3.10 或以上版本：

```powershell
python -m pip install -r B/q1/requirements.txt
python -m unittest discover -s B/q1/tests -v
```

`python` 应指向已安装依赖的解释器。上述命令适用于克隆仓库后的环境，不需要本机的 `.modeling-deps`。算法仅提供 Python 函数，无 CLI 入口。调用方检查返回字典的 `status` 后读取几何结果。

Python 调用：

```python
from B.q1 import solve_bearings

result = solve_bearings([
    {"position": {"x": 0, "y": 0}, "svd_deg": 53.13010235415598},
    {"position": {"x": 600, "y": 0}, "svd_deg": 126.86989764584402},
])
print(result["status"], result["diameter_m"])
```

## 输入输出约定

`solve_bearings(observations, error_deg=1.0, tolerance_m=1e-7)` 接收观测字典列表。每条观测必须且只能包含 `position: {x, y}` 与 `svd_deg`。所有坐标单位为米；示向度从正东方向逆时针计量，角度自动归一化，跨越 0° 不需要特殊处理。不接受 NaN、Infinity 或布尔值冒充数值。

默认误差半宽为题设的 **1°**。可显式传入 `error_deg=1.005` 研究接口保留两位小数的量化裕量；这不是题设误差范围，也不是第一问默认值。半宽需满足 `0 < error_deg < 90`。

主要输出字段：

| 字段 | 含义 |
| --- | --- |
| `status` | `BOUNDED`、`EMPTY`、`UNBOUNDED` 或 `NUMERICAL_ERROR` |
| `vertices` | 逆时针顶点，从字典序最小点开始；不重复首点 |
| `dimension` | 点为 0，线段为 1，二维多边形为 2 |
| `area_m2` | 区域面积，点和线段为 0 |
| `diameter_m`、`diameter_pair` | 最大顶点间距及对应最远点对 |
| `diameter_circle` | 最远点对中点为圆心、D/2 为半径；附最大顶点距离和覆盖差值 |
| `diameter_circle_covers` | 在显式米制容差下是否覆盖所有顶点 |
| `minimum_enclosing_circle` | 最小包围圆的圆心和重新核算的覆盖半径 |
| `tolerance_m` | 几何比较容差，默认 `1e-7` 米 |

EMPTY、UNBOUNDED、NUMERICAL_ERROR 的顶点和圆等几何字段为 `null`；无界区域数学直径为无穷大，JSON 不写非标准的 Infinity。仅 BOUNDED 时读取有限直径。`solve_halfplanes(A, b)` 为可复用的二维半平面入口。

## 算法与第一问结论

观测点为 s、示向度为 θ、误差半宽为 δ，令 l = (cos(θ−δ), sin(θ−δ))、r = (cos(θ+δ), sin(θ+δ))。前向角域由两条约束给出：

```text
(l_y, -l_x) · x <= (l_y, -l_x) · s
(-r_y, r_x) · x <= (-r_y, r_x) · s
```

1. 对全部半平面做线性可行性检查。两个坐标变量均允许为负数。
2. 分别最小化 x、−x、y、−y。任一无界则输出 UNBOUNDED；不通过人工边界框把它变成有限多边形。
3. 有界时枚举非平行边界交点，保留满足全部约束的点，去重并构建凸包。独立核对其坐标极值与 LP 解，避免将数值失败当作空集。
4. 对全部顶点对计算距离，其最大值就是整个凸区域的直径 D。
5. 取最远点对 a、b 的中点 o，检查所有顶点到 o 的距离是否不超过 D/2。

**以区域直径为直径的圆并不总能覆盖区域。** 边长为 2 的等边三角形直径 D=2，但任意最远点对中点到第三个顶点的距离为 √3，大于 D/2=1；最小包围圆半径为 2/√3。若一个半径为 D/2 的圆能够包含距离为 D 的 a、b，其圆心必为两者中点，因此不能通过平移该圆来避开反例。

圆盘是凸集，包含所有顶点等价于包含整个凸多边形。等价覆盖判据为对全部顶点 v 检查 `(v-a)·(v-b) <= 0`。程序输出距离形式的残差 `coverage_gap_m = 最大顶点距离 - D/2`，便于复核容差边界。

程序还输出 `outside_vertex_indices` 和 `max_thales_dot_m2`。前者列出直径圆外的顶点编号；后者是 `(v-a)·(v-b)` 的最大值。最大值不大于 0 表示所有顶点位于以 ab 为直径的圆内或圆上；正值表示至少一个顶点在圆外。

附加的最小包围圆采用小规模参考算法，枚举单点、点对中点、非共线三点外心；对每个候选圆心重新计算到全部顶点的最大距离，并选择最小者。

## 验证与局限

测试覆盖解析矩形、等边三角形反例、点和线段、空集、全平面/楔形/条带/直线/射线无界情形、前向性、跨 0°、近乎平行测向、负坐标、平移缩放、重复观测、逐步加约束单调性和异常输入。另有两组各含 6 个检测点的合成案例：

| 案例 | 直径 D | 覆盖差值 | 最小圆半径/(D/2) | 定位区域特征 | 结论 |
| --- | ---: | ---: | ---: | --- | --- |
| `multi_station_covers.json` | 47.9448m | 约 0m | 1.0000 | 5 个顶点呈长条或钝形；所有顶点对直径端点的 Thales 点积均不大于容差 | 覆盖 |
| `multi_station_not_covers.json` | 22.8974m | 4.5403m | 1.0564 | 5 个顶点中存在偏离直径中点的突出顶点；最大 Thales 点积为正 | 不覆盖 |

两组都使用合成真值 `(250,-150)`，各示向度由对应检测点到真值的真实方位叠加 `injected_errors_deg` 中对应误差得到，且误差绝对值均小于 1°。真值和注入误差只用于测试检查，算法输入仍只有 `observations` 中的检测点和示向度，以及统一误差界。

随机验证使用固定种子：40 个有界测向案例与独立逐边裁剪算法比较，10 组最小包围圆与 SLSQP 凸优化比较。测试中裁剪用的大边界框会检查其是否未激活；正式求解算法不使用该边界框。

若有 n 条半平面、v 个凸包顶点，交点筛选为 O(n³)，直径计算 O(v²)，参考最小包围圆 O(v⁴)。这是少量检测点的透明参考实现，大规模控制循环应另行换用更高效算法并保留本实现做对照。

数值使用浮点而非严格区间计算：法向量归一化，HiGHS 原始/对偶可行性容差为 `1e-9`，几何容差默认 `1e-7m`；夹角极小、极大坐标或极窄区域可能存在误差。容差内合并顶点会使小于容差的区域退化为点或线段。`diameter_circle_covers` 是容差判定，不应当作任意精度的严格数学证书。程序会对主要数值异常返回 NUMERICAL_ERROR，仍不能保证检测所有病态输入。

第一问区域不额外裁入半径 1800m 的目标圆、接收圆或其他物理排除区域。代码没有实现问题二至四的搜索策略，也没有将最小包围圆直接用于自动清除。
