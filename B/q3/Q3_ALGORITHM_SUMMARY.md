# Q3 协同定位与全局路径算法总结（版本 4）

记录日期：2026-09-11。当前默认策略为 `v4_cooperative`。本版本依据
[本轮优化方向](Q3_OPTIMIZATION.md)，在 `v3_global` 上增加固定站顺路复测、
全局区域收缩、定位质量判定和多区域路线优化；`v3_global`、`v2_local`、
`b0_batch_fifo` 与 `b0_serial` 均保留为可复现对照。

实现文件为 `planner.py`、`localize.py`、`geometry.py`，CLI 为
`runner.py`，同图配对验证为 `validation.py`。规划器从不读取模拟器中的
真实干扰源坐标、未来成功清除点或其他隐藏真值。

## 1. 目标、约束与时间

目标圆盘半径为 1800 m；频道为 1—20，每频道至多一个静止源，总源数不超过
16。接收半径未知但位于 1000—1500 m。机器狗速度为 5 m/s，测量耗时 5 s，
切换检测频道耗时 1 s，失败清除耗时 3 s，成功清除耗时 5 s。

```text
T = 路程 / 5 + 5 N_measure + N_switch
  + 3 N_failed_clear + 5 N_success
加权单源时间 = 所有地图 T 之和 / 所有成功清除源数
```

规划计算的现实耗时单独记录，不计入题目的虚拟时间。

## 2. V4 状态机

```text
DISCOVERY
  七站扫描 UNKNOWN 频道
  对 DETECTED 频道评估固定站顺路复测

LOCALIZE_SERVICE
  为所有待处理区域生成“安全测向或认证清除”首选任务
  按区域质量决定继续定位还是进入清除

ROUTE_EXECUTION
  对所有区域任务做最近插入 + 2-opt
  每次测量或成功清除后重新生成任务和路线

EMERGENCY_FALLBACK
  仅在几何失败、无安全计划或认证计划耗尽时使用 152 点条带
```

所有频道仍严格使用 `UNKNOWN / DETECTED / CLEARED / ABSENT` 四态。
只有所有频道均为 `CLEARED` 或 `ABSENT` 且无异常时才有完成证书。
`/exit` 被接受不等同于任务完成。

## 3. 七站发现与顺路复测

覆盖站为原点和半径 1150 m 正六边形的六个顶点。七站覆盖证书保证目标圆盘
中的任意点距至少一个固定站不超过 1000 m。UNKNOWN 频道仍按奇偶站蛇形顺序
扫描；七站均返回 `no_signal` 后才可按覆盖证据标记 ABSENT。已发现源数达到
16 时，可依据数量上界把其余 UNKNOWN 标记 ABSENT，但 DETECTED 源仍须清除。

V3 在某频道首次返回 `direction` 后会在后续站跳过该频道。V4 在每个后续
固定站对该源进行一次价值评估，不会无条件测满七站：

1. 已测过的位置、near 源、无有效凸区域的源直接跳过；
2. 若固定站对整个当前区域保证 999.9 m 接收，使用连续最坏响应完成时间界；
3. 若不能保证接收，但固定站仍可能接收且距区域中心不超过 1500 m，使用
   “区域中心方向响应”作条件价值估计；
4. 新视线与首测方向夹角至少 5°、预计认证点数减少，且扣除 5 s 测量和实际
   频道切换后净收益至少 0.25 s，才执行复测。

第 3 类只是调度启发式，不是接收保证。若实际返回 `no_signal`，V4 仅记录
结果，不将频道改为 ABSENT，也不把接收圆外部直接裁入凸区域。若返回
`direction`，则按与自适应测向相同的保守几何更新区域。这样利用固定路线
机会，同时不因启发式接收失败排除真实源。

每次选择或跳过都记录固定站、是否保证接收、视线夹角、当前与预计认证点数、
测量和切换成本、净收益及判定原因。

## 4. 累计保守区域

首个方向观测形成：

```text
P₁⁺ = 示向楔形外包 ∩ 目标圆 128 边外切多边形
      ∩ 1500 m 接收圆外切多边形
```

示向半角使用 1.005°，包含题设 ±1° 和两位小数读数量化裕量。每个新的
`direction` 将当前 `P⁺` 与新楔形、该测点 1500 m 接收圆外包继续求交。
`region_version` 随成功更新增长，首测锚点保持不变。

自适应测点必须满足对当前凸区域所有可能源均在 999.9 m 内。该检查在凸多边形
顶点上取最大距离即可完成。固定站的非保证复测不属于这种安全自适应测点；
其 `no_signal` 分支因此按上一节安全忽略。

## 5. 定位质量与全局收缩

V4 不再用“方向数达到 2”作为停止条件，也不因连续两个半径改善较弱而提前停止。
每个区域同时记录：

- 最小包围圆半径；
- 凸区域面积、主轴长度和次轴长度；
- 当前认证清除点数；
- 当前认证计划的完成时间上界。

默认质量门槛要求认证点数不超过 4、半径不超过 80 m、面积不超过
10000 m²、计划完成上界不超过 180 s。MEC 单点计划和 near 单点计划直接视为
可清除。未达到质量门槛且仍有安全测向预算时，区域的首选任务为自适应测向；
达到门槛或测向预算耗尽后，首选任务为认证清除。因此两个近似平行方向形成的
长区域不会被方向数量误判为定位完成，必要时可取得第三、第四个自适应方向。

V4 每源最多 4 个自适应测点；固定站顺路复测不占用该额度，也不计入每源
4000 m 自适应闭合路线预算。规划总预算仍为 60 s，单次候选搜索预算为 1.5 s。

## 6. 认证清除计划

若区域最小包围圆半径加裕量不超过 19.9 m，使用 MEC 圆心单点清除。否则枚举
区域边方向、首测方向及坐标轴方向的包围矩形，并用不超过 28 m × 28 m 的单元
中心覆盖：

```text
单元覆盖上界 = sqrt(边长₁² + 边长₂²) / 2 ≤ 19.9 m
```

执行前由 `verify_cover_certificate()` 验证区域完全位于矩形内、单元尺寸、
所有必需中心点及覆盖半径。不会删除落在目标圆外的网格中心，因为该中心仍可能
覆盖区域边界。正常区域即使认证点数较多也不会因此直接转入条带 fallback。

## 7. 多区域路线与动态重排

V4 对每个待处理源只保留当前首选任务：

- 质量不足：最佳安全定位点；
- 质量达标：MEC、near 或矩形网格清除入口；
- 几何异常且无安全计划：紧急条带入口。

任务代价包含当前到入口的移动、频道切换、任务内部动作、覆盖路径及最坏失败
清除时间。定位任务的出口为测点；清除任务的出口为认证计划末点。规划器先构造
覆盖全部待处理区域的最近插入顺序，再用确定性的 2-opt 交换降低完整路线代价。
这比 V3 的单个最近区域一步前瞻更完整，但仍是启发式路线，不宣称 GTSP 全局最优。

每次真实测量更新区域后、每次成功清除后，全部剩余任务都会重新定价和排序。
开始执行一个认证清除计划后会沿其证书路径执行至成功或计划耗尽，避免在单个
覆盖计划内部频繁来回切换。

## 8. 正确性与有限回退

- 复测 `no_signal` 不改变 DETECTED 状态、不增加七站 absence 证据；
- LOCALIZE 不推进七站扫描游标，不修改固定站 absence 证据；
- 所有正常清除点必须来自 MEC、near 或矩形网格证书；
- `FIRST_BEARING_STRIP` 只处理几何失败、无安全计划或认证计划耗尽；
- near 清除失败、条带耗尽、源数超过 16 均报告模型或协议不一致；
- 重复 `propose_action()` 返回同一待执行动作，响应只能应用一次。

CLI 调用方式保持兼容：

```powershell
python -m B.q3.runner --robot-id <队号> --connect-wait-s 60
```

可用 `--strategy v3_global` 显式运行冻结的 V3 对照。

## 9. 审计输出

`summary()` 新增或扩展以下字段：

| 字段 | 含义 |
| --- | --- |
| `source_diagnostics` | 每源固定站/自适应方向数、初末半径和面积、定位事件 |
| `localization_events` | 点来源、响应、入站距离、定位前后质量与认证点数 |
| `revisit_decisions` | 每次选择或跳过固定站复测的成本依据 |
| `latest_planned_region_order` | 最近一次全区域候选顺序 |
| `final_region_visit_order` | 实际成功清除区域顺序 |
| `route_plan_history` | 每次动态重排的区域版本、顺序和路线代价 |
| `localization_inbound_distance_m` | 自适应定位点入站路程，不含固定站顺路复测 |
| `p95_source_service_time_s` / `max_source_service_time_s` | 从首次发现到清除的尾部时间 |

运行器原有 JSONL 会在每次动作后写入动作、决策依据和规划器 summary。

## 11. 同图配对验证

完整结果见 [V4 离线验证结果](validation_results_v4/paired_results.json)。验证使用
随机种子 20260911 生成的 24 张固定地图、306 个源；V3 与 V4 对每张地图使用
完全相同的频道、源位置、接收半径、误差模式和响应规则。隐藏真值只在验证环境
中生成响应和检查包含关系，不进入规划器。

| 指标 | V3 冻结对照 | V4 协同优化 | 变化 |
| --- | ---: | ---: | ---: |
| 完整清除 | 306/306 | 306/306 | 不变 |
| 加权单源虚拟时间 | 391.002 s | 330.596 s | −15.45% |
| 每局平均时间均值 | 395.842 s/源 | 336.334 s/源 | −15.03% |
| 每局平均时间 P95 | 471.368 s/源 | 441.851 s/源 | −6.26% |
| 每局平均时间最大值 | 495.554 s/源 | 458.473 s/源 | −7.48% |
| 单源服务时间 P95 | 4518.435 s | 3726.298 s | −17.53% |
| 单源服务时间最大值 | 5711.085 s | 4570.508 s | −19.97% |
| 总路程 | 509973.125 m | 418542.632 m | −17.93% |
| 自适应定位入站路程 | 232471.099 m | 135668.857 m | −41.64% |
| 失败清除 | 370 | 109 | −70.54% |
| fallback 源数 | 0 | 0 | 不变 |
| 总测量数 | 2553 | 2629 | +2.98% |
| 自适应测量数 | 455 | 213 | −53.19% |
| 固定站顺路复测 | 0 | 318 | 新增 |
| 规划现实耗时（24 局合计） | 332.515 s | 223.559 s | −32.77% |

V4 在 24 张地图中的 23 张降低了平均虚拟时间；案例 8 退步
18.835 s/源，因此不能声称逐图必然更快。V4 的 306 个最终局部计划平均
1.755 个清除点、最大 4 点；V3 为平均 2.592 点、最大 16 点。V4 共完成
213 次安全自适应测点检查、831 次真实源仍在保守区域内的检查及 409 次实际
清除动作证书检查，未发现违规。两版均无 fallback。

总测量数增加是本轮主要代价：318 次固定站复测替代了一部分远距离自适应测量，
净增加 76 次测量，但节省了 91430.493 m 路程并显著减少失败清除。

这些结果只支持固定离线案例集上的配对改进，不是官方模拟器成绩，也不能证明
参数对所有地图最优。
