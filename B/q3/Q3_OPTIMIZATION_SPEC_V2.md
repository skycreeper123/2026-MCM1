## 1 结论与证据层级

主路线是“七站发现 → 本站扫描集中完成 → 批次内逐源服务 → 累计集合定位 → 比较继续测向与覆盖清除 → 有预算的原条带回退”。先把每站多个频道一起发现，随后连贯处理本批目标，避免每清除一个源就回站；不等全七站扫描完才开始清除，也不在 V2 中跨站积压已发现目标。

首次真实演练：13/13 清除，8134.791492 s，625.753192 s/源，83 次检测、587 次失败清除、29088.957458 m 移动。仅一个案例，不能据此估计随机总体效果。

独立日志反事实：每站先完成原有测量，再按原发现顺序执行各频道原有清除点列；每频道动作顺序、位置和成功序号完全保持，重算移动和切换。得到 7495.932525 s、576.610194 s/源，减少 3194.294831 m、638.858966 s（7.8534%），失败次数仍为 587。该比较不使用未来成功位置选择顺序，不使用隐藏源坐标。题设下各频道独立、源静止且同点误差固定，因此可沿用这些反馈；它是有效的轨迹反事实，不是官方重跑或 V2 整体成绩。该日志没有 near，含 near 的一般策略另按第 3 节处理。

Q2 公共探测：首次站 (0,0)、示向 0°、误差半宽显式 1.005°，用新版默认候选规模及每次5 s协作预算，分别检查λ=0与λ=1的第二点安全性和72个公开保守角域场景。实际选点、包围半径、耗时以 `Q3_DESIGN_CHECKS_20260911.json` 为准。这些场景用于发现“二次测向后区域仍大”的情况，不是官方误差分布或成功率估计。Q2连续响应上界的依据是区间外包证明，公开样本仅用于交叉核验。

同步说明：此前读到的是Q2旧版，旧判断中“仅有限响应样本评分”“预算不含初始化”“超时无已评估候选便失败”已不适用于新版。新版已修复；本站批处理反事实、累计观测需求、Q3时间目标、原条带回退仍成立。最终策略改为复用连续响应区间，而非在Q3重新退回三个误差采样的最坏评分。

## 2 Q2 更新对 Q3 的影响与接口缺口

当前可调用：

```python
    first_observation={"position": {"x": ax, "y": ay}, "svd_deg": theta},

    used_positions=[{"x": x, "y": y} for x, y in channel_measure_positions],

```

`current_position` 必须是狗的当前位置，不是默认为首测站。`used_positions` 仅含该频道的历史检测点，不能禁止其他频道使用同一空间位置。Q2 输入对象严格校验字段；日志时间、频道和 station_id 不可塞进 `first_observation`。

## 3 本站扫描批处理与状态机

保留固定七站和固定访问顺序。每个站 A 分为 SCAN 与 SERVICE 两个阶段：

1. SCAN：原地检测仍为 UNKNOWN 的频道，升降序交替。direction 保存首次锚点、观测和初始外包，加入本批队列；继续扫描下一个频道。near 原地立即 clear，再恢复扫描。合法无信号只记当前站当前频道证据。
2. 本站 UNKNOWN 扫描完成后进入 SERVICE。FIFO 是最小实现版；增强版按第 6 节估计完成代价选一个目标，服务至清除成功或明确异常，再选择下一个目标，不在多个未完成源间来回切换。
3. 本批全部已发现源清除后，从实际终点直接去下一个覆盖站 B。不要为了“回到扫描流程”发一个多余测量；下一次正规 measure 自带移动。第七站服务结束后不要求返回。

频道状态用业务状态与局部阶段分开表示：

```text
status: UNKNOWN -> DETECTED -> CLEARED
                       UNKNOWN -> ABSENT (必须有证书)
service_phase: NONE / READY_CLEAR / LOCALIZING / COVERING / FALLBACK
```

near 属于 DETECTED+READY_CLEAR，原地请求优先。READY_CLEAR 不是 CLEARED。所有 DETECTED 状态均不能因后续 no_signal 变成 ABSENT。为确定性终止，本版服务到一半不跨站延期；跨站批量定位另开后续版本重新分析。

测量动作增加 `purpose=COVERAGE_SCAN|LOCALIZE`。`station_id` 仅在确实到该覆盖站执行相应排查时填写；几何上接近不能自动视作同站。现有 `apply_measure_result` 无条件 `scan_cursor += 1` 以及写入 `no_signal_station_ids`，必须改为只在 COVERAGE_SCAN 的合法响应上执行。首次锚点只赋值一次，新增定位观测追加存储。

完成证书有两种：

- 16 个不同频道成功清除，使用 `MAX_SOURCE_COUNT_REACHED`；剩余 UNKNOWN 可保持原状态，或以 `COUNT_UPPER_BOUND` 为独立 absence_reason，不能伪造七站记录。
- 所有频道均 CLEARED，或 UNKNOWN 经七站合法 no_signal 变成 ABSENT。SERVICE 中仍有 DETECTED 时绝不能退出并声称完成。

如果首次方向证据数与成功计数等信息违反总源数上限，应报数据一致性异常，而非强行套用计数停止条件。

## 4 累计集合定位与数值要求

每个频道维护：

```text
P_c+ = target_disk_outer
       ∩ 所有 direction 的前向角域(±1.005°)
       ∩ 所有 direction 测点的 1500m 接收圆外包
```

初始化沿用 Q2 的外切 128 边形。direction 每次只增加约束；保留原始观测以便完整重建。near 无需依赖旧外包，原地 clear；若合法 near 原地清除却失败，应记录模型/协议异常，不能继续生成假定位点。

MEC 返回中心 o 后，重新计算所有顶点最大距离，并计入约定的外包数值裕量。只有验证覆盖半径 ≤19.9 m 才允许发保证型 `clear(o,c)`。外包包含性及退化处理仍需几何测试；浮点参考代码不等同于形式化精确证书。

no_signal 不裁剪 V2 的主凸外包。全向源可据此排除开/闭边界处理正确的 1000m 接收圆内部，但将产生非凸结构；为避免几何复杂度，暂只保存证据。普通局部覆盖失败也保留当前外包，不用错误的半平面近似“挖洞”。

空交集、异常顶点、非有限数、安全候选却收到 no_signal，均禁用该频道的主动几何，回到不可变首次锚点的完整条带。保证清除意外失败同样记录异常并最多回退一次；若完整条带仍耗尽则明确失败，不循环。

## 5 少量区域覆盖与首次条带

### 5.1 交会后不必执着于再测一次

用 P_c+ 的矩形外包生成确定性清除点。候选朝向可取首测方向和外包边方向；对每个朝向，投影极值给出长 L、宽 W，使用

```text
nL = max(1, ceil(L / 28))
nW = max(1, ceil(W / 28))
```

等分矩形，在每个小格中心 clear。每格边长不超过 28 m，因此所有点距本格中心 ≤14√2=19.798990 m。点或线段退化取单格/单列，不除以零。投影边界向外放松，计入数值裕量后仍应满足 19.9 m 策略阈值。

首版保留完整外包矩形的格点，不做“只有顶点落入才保留”的裁剪。每源优化清除总额暂设 8 次（包括直接清除、局部覆盖和主动阶段 near 的清除；不含后续完整条带）。只接受能在剩余次数内执行完整的局部覆盖计划，且满足第 7 节路长预算；不要先跑 8 点再把未覆盖尾部默默丢掉。

选择多种蛇形方向、起始角，按从当前位置 p 开始且接上下一覆盖站 b 的完整路线成本比较。给定 N 点序列 Q：

```text
U(Q; p,b) = [dist(p,Q[0]) + route_length(Q) + dist(Q[-1],b)] / 5 + 3N + 2
```

最后站无后继时去掉末段。若提前成功，从成功点直接去 b 不长于继续整条 Q 再去 b，故 U 是含后继连接的终止计划上界。区域覆盖的保证来自连续矩形覆盖，不是采样点全部命中。

### 5.2 首次条带暂保留 152 点作为最终锚点回退

原 152 点、20m 步长、±15m 行偏移已经在现有测试和首次演练中使用。V2 首个集成版本保留它，以隔离定位与调度变化。

第6节若要把它当作覆盖整个浮点外包P的终止计划，还需检查外切圆的超出量。固定128边时，R_outer=1500/cos(π/128)，约1500.452m；首方向投影t在[0,R_outer]，横向幅度≤R_outer·sin(1.005°)<26.4m。末端超出1500m小于10m，其余纵向最近格点距离≤10m，横向最近行距离≤15m，故152点仍覆盖这一更大的矩形。修改圆边数、误差或条带参数时必须重新验证该外包覆盖，不能仅凭覆盖物理圆的旧证明给任意E(I)作保证。

104 点候选可作为独立消融：

```text
q(k,±) = anchor + (1500*k/51)*u ± 13.2*n, k=0,...,51
```

最坏距离 19.761148 m，闭路线 3052.8 m，单源回站计费上界 924.56 s。单独替换原串行 B0 时，总上界 17012.96 s、1806 请求。这些数值已解析复核，但它缩小了原方案的覆盖裕量；须测试旋转、量化、端点和坐标序列化，不能直接宣称实际平均成绩提高。

不能因某个 clear 点位于半径1800m圆外就删除它。圆外点仍可能覆盖圆内源，例如源(1799,0)、清除点(1805,0)，距离仅6m。合法删点依据必须是“删除后剩余清除圆仍覆盖整个可行域”；只算中心线与目标圆交点也不能覆盖完整有宽度扇形。优化几何一旦失效，回退须恢复完整原点列，而非沿用可疑删点结果。

## 6 选点和调度目标统一为剩余虚拟时间

本版不以“第一次清除成功率”单独选策略。有时花6秒以内覆盖两点，比移动数百米去补测更快；也不能因本案例第一条偏移行成功较多就假设误差偏向固定一侧。

### 6.1 单源当前动作与连续响应完成时间上界

先构造无需新增测向的终止计划集合：MEC 单点（若有证书）、完整少量网格覆盖（若满足8次余额）、原152点条带。对所有符合预算的计划比较 U，得到 U_now。局部网格计划与原条带的覆盖依据不同，但都必须有连续区域保证。

还有测向额度时，Q2安全域产生候选s；对全部外包顶点复查安全性、排除该频道已测过位置，先过滤路长预算。候选可加入安全且未重复的当前位置、朝后继站方向代表点、见证点，以及显式λ=0和λ=1的Q2代表点。宜共享一次初始化和候选集合，避免每个权重完整重复初始化。有限候选不保证空间全局最优。

V2复用新版Q2的完整读数域和区间外包。对读数区间I=[m-h,m+h]，构造E(I)=P∩W(s,m,δ+h)，可再与s的1500m接收圆外包相交。若δ+h≥90°，以整个P（或P与接收圆外包）作保守替代。对E(I)生成第5节的合法终止计划，并把对应计划保存下来：

```text
C(I) = min_{Q covers E(I), within remaining budgets} U(Q; s,b)
J_upper(s) = dist(p,s)/5 + 5 + int(channel != tuning_channel)
             + max(max_I C(I), 5 + dist(s,b)/5)
```

第二个max项保守包含near分支：原地清除5秒及接上后继站；最后站去掉后继距离。空区间不需服务，贡献0；任何数值异常区间退回完整P的终止计划，不能误删。完整首次条带始终是候选终止计划之一，因此初始完整读数域也能获得有限代价界。局部网格、MEC等优化清除必须满足8次剩余额度以及4000m预算。

证明：每个真实direction读数属于某个叶区间I，其更新区域包含于E(I)，所以缓存的Q_I一定覆盖该更新区域；提前成功不会使接上后继站的路径变长。因此max_I C(I)覆盖全部direction分支，而非有限误差采样。收到真实读数后，可执行对应Q_I，或采用经过认证且U不大于该缓存代价的更好终止计划。若选择再次测向则是下一轮决策，不得把原来“一次测向后立刻终止”的界当作整个多步过程总界；全程仍由第7节约束。

初始化保留一个覆盖全读数域的父区间及完整可执行计划。优先细分C(I)最大的区间；两个子区间的几何和计划均完成才替换父区间。子区间还可继承父计划作为候选，保证细分不会丢掉已有可执行上界。预算耗尽保留完整分割。初始建议最多32个叶区间、12个粗候选、8个细候选；按现实预算调节，分割少使界松但不改变覆盖性。

这是拟新增的 `response_completion_bound`，当前Q2仅返回半径界，不返回区间外包、覆盖计划或时间界，需要实现Agent补齐/公开区间遍历接口。单个U(s)半径值不能直接乘常数换成完成时间，因为移动到清除点的距离及覆盖点数量也在变化。若最小适配尚未实现此函数，保留现有Q2半径候选和明确标记的启发式选择，不可提前声称已有连续时间界。

只有最优J_upper比U_now至少少10秒且预算允许时才新增测量，否则执行当前终止计划。10秒是待调阈值。比较的是可执行计划的保守上界，不能推出在每个具体源位置上都比B0实际提前成功更快；有限候选和松上界也可能保守地放弃有利测向。

第二点之后按累计外包重新评价，仍显式使用1.005°。Q2输出的半径上界只用于预估与选择，实际clear中心必须由真实响应更新后的区域决定；即便U≤19.9也不能在测量之前猜测后续圆心。每源最多3次额外测量，两次实际更新均无明显收缩（建议半径下降<5%）时结束测向。

### 6.2 本批服务顺序

最小实现使用FIFO，并保留对照结果。增强版在每次成功清除后重算待处理源，比较当前U_now或候选J_upper的较小值，减去公共直达后继站成本dist(p,b)/5后取最小；平局按首次发现顺序、频道号确定。为限制计算，可先按当前终止代价筛最多3个服务候选源，缓存其与位置无关的外包/响应区间；每次重用计划必须按当前位置和剩余预算重新计费。当前服务源未完成时不被其他源抢占。

这个分数是“先服务一个源再接回发现路线”的局部代理，并非完整多目标最短路。前一源清除后的真实位置可使用，因为那是狗已知的位置；未访问目标的成功位置不能预先用于排序。首版不做跨站延期、不强制每个测点扫20频道、不使用全局最优/TSP 等未经验证的称谓。

更进一步的共点补测应放在后续版本：安全性逐频道判断，额外频道切换及5秒检测都收费，并占该频道额度。引入这种交叉服务会改变第7节按单源连续服务分解的证明，不能自动沿用上界。

## 7 有限完成保证和预算记账

默认每源首次发现后K=3次额外测量、最多8次优化清除、虚构回到本批站A的优化段路长≤4000m。优化测量返回near时，必须预留其原地clear的1次优化清除额度；若清除额度用完，不再启动新测量。A就是本批所有direction源的首次发现锚点。对该源已经执行的优化点序列x1,...,xj，记

```text
L_prefix = dist(A,x1) + sum(dist(x_i,x_{i+1}))
```

每个新优化动作到 q 之前检查 `L_prefix + dist(xj,q) + dist(q,A) <= 4000`，首个动作使用 `dist(A,q)+dist(q,A)`。这里虚构从 A 出发用于证明；实际狗从前一源结束点直接走向 q。真实路长仍按实际当前位置另账统计，不能混用。

优化耗尽后，从实际位置直接去首次完整条带的第一个点。用于上界可想象先回 A，再执行原条带并回 A。每个源的虚构闭合服务段串联时，由三角不等式删去实际不需要的回站折线，得到本批实际行走不超过这些闭合段之和。七站发现路线仍为6900m。

因此在题设成立、所有动作合法执行且现实时间充足的条件下：

```text
Q3 V2 virtual upper bound
<= 19340 + 16*(4000/5 + 3*6 + 8*5)
= 33068 s

logical requests <= 2574 + 16*(3+8) = 2750
```

这是故意重复计费的安全上界，目标是改善平均与尾部实际表现，不是缩小这个松上界。若使用104点最终回退并完成其验证，相应上界才可重新计算。跨站服务、交叉补测、超过额度或改变站序，都需要更新证明。

严格终止性：七站至多140次覆盖检测；每站扫描计数单调；每源优化测量和清除计数有上限；失败进入有限原条带；成功永久移出队列；最终凭计数或七站证书结束。异常不等于已完成。

现实预算：初始建议预留30s退出余量、整局选点累计计算预算60s、单次选点目标1s。参数只是待调初值，不是实测硬保证。使用 enter 返回的剩余时间建立绝对单调时钟 deadline，计入 enter 响应传输耗时裕量；规划开始前、候选生成、区间细分和动作提交前都检查。达计算预算时停止几何选点，顺次清理队列并完成覆盖；若现实剩余不足以执行剩余安全任务，则记录 `TIME_BUDGET_INCOMPLETE` 并退出，不能声称保证完成。

首次真实8.554秒说明本案例通信并非主要瓶颈，但 Q2 单次搜索增加计算，不能从 B0 速度推断新版本整局运行时间。当前 Q2 函数不是可抢占的硬实时函数；重计算长调用必须增加内部截止检查，不能只在函数返回后判断超时。

## 8 实现状态与迁移清单

现有 `Q3Planner.propose_action()` / `apply_*_result()` 的单个待定动作契约可保留，新增内部状态：

```text
Planner: SCAN/SERVICE, batch_station_id, scan_cursor, batch_channels,
         active_service_channel, real_deadline, total_planning_time
Channel: immutable_anchor, observations, outer_vertices, geometry_valid,
         measured_positions, extra_measure_count, optimized_clear_count,
         artificial_prefix_length, local_cover_plan/index, fallback_index
Action: existing fields + purpose + region_version + decision_budget
```

状态只在合法 accepted 响应提交后推进。候选计算和反复 propose 不计动作次数；已选动作锁定，重试不得重算坐标。频道切换只在 measure 时改变，clear 成败都更新位置。

建议实现文件：新增 `B/q3/localize.py`（共享几何适配、覆盖计划）、修改 `planner.py`（阶段/批队列/预算）、修改 `runner.py`（规划前截止参数、结果分类和新配置）、扩展依赖与测试。Q1/Q2 共享逻辑应公开复用接口，不复制后各自漂移。

`runner.py` 当前在 `action.kind == EXIT` 且退出响应成功后无条件设置 `completed=True`。必须分为 `exit_accepted` 与 `task_completed`：后者要求停止证书有效，且不处于模型异常或预算不足。当前先 `propose_action()` 后检查时间，也必须前置检查并把 deadline 传给规划器。仅协议退出成功不能写“全部清除”。

原 B0 默认、配置和回归上界保留，新增显式 `strategy` 区分 B0 与 V2；自检必须报告实际选用策略、依赖、参数、理论边界及版本哈希，不能在 V2 模式打印旧 B0 上界冒充本策略保证。

## 9 实施顺序与验收

1. `B0_batch_fifo`：只做本站先扫再清，保持152点及原服务顺序。重放本次公开日志，复核638.858966秒路径收益；补测 near 打断扫描后恢复、16源提前结束。
2. `V2_local`：接 Q2，统一1.005°，保存累计区域，增加保证单点/小网格与原条带三种终止方式；先沿用 FIFO，隔离局部定位收益。
3. `V2_time_score`：累计区域下次选点、完整响应区间的完成秒数上界、每源额度和截止时间；测试细分中断保留父计划，并比较测量次数、失败次数及虚拟总时间。
4. `V2_batch_order`：加入服务顺序评分，和 FIFO 做同例比较。104点条带作为独立开关；非凸无信号裁剪及跨站共享均另行版本化。

同步后当前Q2有29项测试通过，Q3扩展为27项测试通过；仍应继续补齐下列 `V2_time_score` 专项检查：

- 真实误差加两位小数量化的最不利1.005°、359.99°跨零，真源始终被外包保留。
- 二次测向后半径仍>20；第三点使用累计区域；同频道不得原地重复；两个频道可在同点测。
- 19.9m覆盖边界、28m格子角点、退化矩形、圆外清除点不能误删；最小圆非必要但最终覆盖复核必要。
- LOCALIZE 不推进扫描游标，不把 station_id=None 计成站点证书，不覆盖首锚点。
- 扫完本批才服务；批次结束无 DETECTED；近距优先后继续原扫描；从前一个成功点直达下一任务。
- 安全点无信号、几何空集、保证清除失败、网格耗尽，均进入有限完整回退；最后回退耗尽报告失败。
- 所有优化点与回站距离都入4000m预算；重试不重记动作；队列和计数不会因 propose 重复增加。
- 规划前后和内部阶段的现实预算、尾部网络延迟、未决请求处理；异常 EXIT 不记 task_completed。
- 全读数域覆盖、δ+h≥90°分支、部分子区间计算超时、near分支额度、真实读数使用缓存覆盖计划；连续时间上界的密集方向独立核验。

公开性能案例覆盖10–16源、最小接收半径、圆周夹角边界、成簇/分散位置、固定正负极端误差以及固定位置空间误差场。同一案例同一确定性误差函数用于所有策略；不可使用随策略请求顺序重抽的随机误差。控制策略只能见反馈，测试世界真值只用于计分与断言；Agent D 不读取封闭集。

逐例输出 full_clear、completion_reason、virtual_total、average_clear_time、distance、scan/localize_measure_count、switch_count、failed_clear_count、cover_count、fallback_count、planning_time、real_time。跨例比较均值、中位数、P95、最大值，并公开样本数。若某些案例退化，列出幅度和原因；不把“每项指标必须全优”当作数学必要条件。主要依据仍是无已知漏源/错误完成、完整时间账和可靠性，其次看总体及尾部代价。

官方原案例不能因改变测点而凭旧日志推断新方向响应。本文的 FIFO 反事实成立，是因为每频道所有检测与清除位置未变；Q2/V2 整体效果需要完整离线新案例和新的官方演练。
