# Q3 V3 离线配对验证报告

日期：2026-09-11。运行环境为 Python 3.12.14、NumPy 2.5.3、SciPy 1.18.1。本报告仅包含自建离线环境；没有连接官方模拟器。

## 实验口径

主命令：`python -m B.q3.validation --cases 24`。每例独立使用种子 20260911 + case_id，源数依次循环 10—16。每四例分别为：目标圆边界与最小接收半径、包含原点 near 的随机区域、交替正负极限误差、位置相关固定误差。全部源和接收半径在两个策略之间完全相同。

规划器只接收动作反馈；环境持有的真值仅用于模拟响应和断言检查。单次任务同时核验幂等性；最多 10000 个逻辑动作，超限即验证失败。P95 与最大值默认以各局“总虚拟时间/成功清除数”为样本，不是单个源的首次发现到清除时间分布。

## 汇总

采用 24 个固定离线案例、306 个源，包含目标圆边界、1000 m 接收下界、原点 near、正负极限误差、交替误差和位置相关固定误差；示向读数保留两位小数。两版使用相同源位置和响应规则，均清除 306/306 个源。V2 使用旧默认参数，但与 V3 共享当前的几何修复，不是旧提交的原样重放。

V3 的每局平均清除时间均值下降 10.53%，加权平均下降 11.09%，失败清除次数下降 67.14%。24 例中 18 例时间改善、6 例退步；最大单例退步为案例 10 的 79.890 s/源。因此不能声称逐例必然更快。

V3 共通过 455 次安全测向核验、755 次真源包含核验及 667 次实际清除动作的局部几何证书核验，未发现违规；near 动作依据独立的 5 m 证书处理。共启用 306 个局部计划，其中 133 个单点计划，平均 2.592 点、最大 16 点，本轮没有计划超过 16 点优先测向阈值。超过阈值且预算耗尽时继续局部网格的分支另由单元测试覆盖。

最终 Q3 单元测试共 42 项通过，0 失败、0 错误、0 跳过；包括原有测试和全局发现、重排、覆盖内部点、错误证书、预算耗尽、几何异常及条带耗尽等新增测试。主配对使用的六个 Python 文件哈希与最终文件一致，详见 [验证记录](verification.json)。

本结果支持“在该离线固定案例集上完整清除，且时间与失败清除总体改善”。额外测向和规划计算时间有所增加；官方模拟器连接、真实协议运行计时及官方演练成绩不在本次验证范围内。

## 验收与限制

预先设定的性能门槛：完整清除率不下降；失败次数减少且回退源数不增加；均值/P95/最大值至少一个改善 5%，其他同级时间指标不恶化超过 10%。本轮 `performance_acceptance=true`。所有正确性断言通过。

上述指标是固定合成集合的描述统计，未进行官方案例泛化或统计显著性证明。6 个参数矩阵案例的附加命令已提供，但本轮没有运行该矩阵；没有将未运行的参数消融、2-opt 或官方演练列为已完成验证。

现实耗时受机器负载和协作式搜索预算影响。`planning_time_s` 统计规划阶段；`wall_time_s` 还包括状态更新及验证环境开销，二者不能混用。重跑时点位可能因预算截断有所变化。
